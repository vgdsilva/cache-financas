# Plataforma de Finanças (nome a definir)

Plataforma web privada de finanças pessoais, auto-hospedada em VPS, para uso de um grupo pequeno de pessoas (o autor, a esposa e amigos). Instalável no iPhone como aplicativo (PWA).

## Como manter esta documentação

- Toda decisão nova entra primeiro no [registro de decisões](decisoes.md), depois é refletida no documento correspondente.
- Itens ainda não decididos ficam marcados como **Em aberto**.
- A documentação vive no repositório, junto ao código, e é atualizada no mesmo pull request que muda o comportamento descrito.
